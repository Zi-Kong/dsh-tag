# 聊天标签 Chat Tags

给聊天的任意片段打标签，标签有可自定颜色，之后可以从侧栏轨道或总览面板一键跳回。

## 用法

1. 在聊天里选中一段文字，气泡条上会多出第三个按钮「标签」。
2. 点击后弹窗：选已有标签，或新建一个（名称 + 颜色），可写标题和备注。
3. 保存后，聊天区左侧出现一颗对应颜色的点，鼠标悬停显示标题，点击直接滚回该处（跨会话也能跳）。
4. 左栏面板图标「标签」打开总览：按标签筛选、改标签颜色、编辑标题、删除、跳转。

## 数据

标签与标记保存在 Host 侧 `$DSH_HOME/storages/dsh-chat-tags/data.json`，全局共享（不按工作区切分），每条标记记录来源 sessionId 与 turn seq。
Agent 也可通过 `chat_tags_list` / `chat_tags_mark` / `chat_tags_delete` 读写。
